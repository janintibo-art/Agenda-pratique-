01 / DÉCOUVRIR

Un agenda à portée de main.

01

Sur ton téléphone

L'application est empaquetée pour Android avec Capacitor : son interface est intégrée à l’APK, sans site web à ouvrir pour la lancer.

02

Widget d’accueil

Un widget Android natif est intégré au processus de compilation. Ajoute-le depuis le menu des widgets de ton téléphone.

03

Agenda et rappels

Organise les tâches par catégorie et priorité, ajoute une échéance, des sous-tâches et un rappel. Le calendrier présente les journées à venir.

04

Journal quotidien

Une page par jour pour écrire, retrouver les notes précédentes et noter ton humeur ou ton intention.

05

Carnet de notes (V3)

Des notes indépendantes des dates, avec titre, couleur, recherche, épinglage, listes à cocher et corbeille. La V3 ajoute photos, messages vocaux, dictée via Android et création de rappels depuis une note.

06

Sauvegardes locales

Exporte et restaure tes tâches et notes, y compris les pièces jointes V3, au format JSON depuis les réglages. Aucun compte obligatoire.

07

Ambiance zen

Fonds personnalisables, thèmes clair et sombre, musique d’ambiance, respiration guidée et réglage de confort visuel à trois niveaux.

03 / PREMIERS PAS

Installer en trois étapes.

1

Télécharge le fichier APK

Choisis la version publiée depuis cette page ou depuis GitHub Releases. Le fichier doit porter l’extension .apk.

2

Ouvre le fichier sur Android

Si Android demande une autorisation, autorise temporairement l’installation depuis la source utilisée (navigateur ou gestionnaire de fichiers). Tu peux la retirer ensuite.

3

Lance Mon Agenda

Retrouve l’icône de l’application. Pour le widget, maintiens ton doigt sur une zone vide de l’écran d’accueil, ouvre Widgets et cherche Mon Agenda.

Avant une mise à jour : sauvegarde tes données si l’application le permet. Si Android refuse l’installation à cause d’une signature différente, ne désinstalle pas l’ancienne version avant d’avoir protégé tes données. Les compilations actuelles utilisent un APK de test (debug).

04 / MODE D’EMPLOI

Prendre des notes sans contrainte.

1

Ouvre Notes

Choisis Journal du jour pour écrire sur une date ou Carnet de notes pour créer une note indépendante.

2

Crée une note

Appuie sur + Note, écris un titre et un contenu. Tu peux choisir une couleur, épingler la note ou ajouter des éléments à cocher. Le carnet enregistre tes modifications automatiquement. En V3, les boutons Photo, Enregistrer et Dicter permettent d’enrichir une note. La dictée dépend du service vocal disponible sur ton téléphone.

3

Retrouve et protège tes notes

Pour un rappel, ouvre la note puis choisis Créer un rappel. Pour un anniversaire, choisis Chaque année dans la répétition : la prochaine occurrence est créée lorsque tu termines la tâche. Utilise la recherche pour retrouver une note, ou la corbeille pour restaurer une note supprimée. Dans les réglages, exporte régulièrement une sauvegarde JSON et garde-la dans un endroit sûr.

05 / QUESTIONS FRÉQUENTES

Besoin d’un coup de main ?

Pourquoi le téléchargement n’est-il pas encore disponible ?

Une compilation réussie ne suffit pas : son APK doit être publié dans GitHub Releases. Cette page détecte automatiquement la dernière publication contenant un APK.

Faut-il un compte GitHub ?

Non pour télécharger une publication d’un dépôt public. Les artefacts de compilation GitHub Actions, eux, peuvent exiger une connexion.

Une connexion Internet est-elle nécessaire ?

Elle est nécessaire au téléchargement. L’interface de l’application est embarquée dans l’APK. Les tâches et les notes sont stockées localement. Les polices distantes peuvent être indisponibles sans connexion ; l’interface utilise alors les polices du téléphone.

Comment signaler un problème ?

Utilise les tickets GitHub si disponibles, en indiquant la version, ton modèle de téléphone et les étapes du problème. N’ajoute pas de rendez-vous personnels ou de données confidentielles.
